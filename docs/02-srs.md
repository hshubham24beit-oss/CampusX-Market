# Software Requirements Specification (SRS)

## Project Name

CampusX Market

## Version

1.0 (MVP)

---

# 1. Introduction

CampusX Market is a web-based marketplace developed exclusively for students of Pillai College of Engineering. The platform enables students to buy and sell second-hand products within a trusted college environment.

The objective is to provide an affordable, secure, and user-friendly marketplace where students can easily exchange useful products such as books, electronics, project components, hostel essentials, and sports equipment.

---

# 2. Purpose

The purpose of this project is to create a dedicated marketplace that helps students save money, reuse resources, and connect with fellow students through a trusted platform.

---

# 3. Scope

Version 1 (MVP) includes:

* Student Registration
* Student Login
* User Profile
* Product Listing
* Product Search
* Product Categories
* Product Details
* Shopping Cart
* Order Management
* Buyer-Seller Chat
* Ratings & Reviews
* Admin Dashboard

Version 1 does not include:

* Rent Module
* Exchange Module
* AI Features
* Multi-College Support
* Mobile Application

---

# 4. Objectives

* Build a secure student marketplace.
* Encourage reuse of educational resources.
* Provide a trusted buying and selling experience.
* Create a scalable platform for future expansion.
* Develop a real-world full-stack web application.

---

# 5. User Roles

## Student

Students can:

* Register
* Login
* Manage Profile
* Add Products
* Edit Products
* Delete Products
* Buy Products
* Chat with Sellers
* View Orders
* Give Ratings and Reviews

---

## Admin

Admin can:

* Manage Users
* Manage Products
* Remove Fake Listings
* Handle Reports
* Monitor Platform Activity

---

# 6. Functional Requirements

The system shall:

* Allow student registration and login.
* Allow students to manage their profiles.
* Allow students to create product listings.
* Allow students to search products.
* Allow students to view product details.
* Allow students to purchase products.
* Allow buyer and seller communication.
* Allow order tracking.
* Allow ratings and reviews.
* Allow admin management.

---

# 7. Non-Functional Requirements

The system should:

* Be responsive on desktop and mobile.
* Load pages quickly.
* Secure user data.
* Use encrypted passwords.
* Provide a simple and modern user interface.
* Be scalable for future development.

---

# 8. Assumptions

* Every user is a student of Pillai College.
* Users have internet access.
* Users provide accurate registration details.

---

# 9. Constraints

* One account per email.
* Only legal products are allowed.
* Only registered students can access the marketplace.

---

# 10. Future Scope

Future versions may include:

* Rent Marketplace
* Product Exchange
* AI Product Recommendations
* AI Price Prediction
* AI Chat Assistant
* Multi-College Support
* Mobile Application

---

# Conclusion

CampusX Market aims to become a secure and trusted marketplace for college students while providing a scalable foundation for future AI-powered features and expansion.
